# Roadmap — Cars Landing Page

## Контекст

Перший реальний проєкт, щоб обкатати глобальний конфіг `~/.claude/` (правила, стиль
спілкування, file conventions, ideas-workflow) на справжній роботі, а не в теорії.
Мета подвійна: (1) зробити чистий базовий лендінг і (2) натренувати roadmap-дисципліну —
зафіксувати дорогі-для-зміни рішення на старті, щоб не вертатись до великих переробок.

## Зафіксовані рішення (фундамент)

- **Стек:** чистий HTML5 + CSS. Без SCSS, без build-кроку.
- **Як запускається:** Live Server (розширення VS Code) віддає `index.html` напряму.
- **Тема:** автосалон / вітрина машин, з реальними марками (BMW, Audi, Mercedes,
  Porsche, Tesla, Toyota...).
- **Адаптивність:** mobile-first (`min-width` media queries масштабують вгору).
- **Іменування:** BEM (`block__element--modifier`).
- **Сучасний CSS:** custom properties, `clamp()` для плавної типографіки,
  CSS Grid + Flexbox, семантичні теги HTML5.
- **Version control:** `git init` + дрібні коміти-чекпоінти після кожного кроку.
  Гілка `main`, без feature-гілок (повний Git Flow — на майбутнє).

## Git workflow (чекпоінти)

- `git init` як найперший крок.
- `.gitignore` одразу.
- Коміт після кожного кроку збірки — кожен крок = окремий чекпоінт.
- Коміт тільки конкретних файлів, не `git add .`. Повідомлення коротке, по суті.
- Гілка `main`, без push (репозиторій локальний).

## Структура файлів

```
cars-landing-claude/
  index.html
  css/
    reset.css        # мінімальний сучасний reset
    style.css        # усі стилі проєкту, розбиті на секції коментарями
  assets/
    images/          # фото машин / іконки
  .gitignore
  ROADMAP.md
```

## Секції сторінки ("каркас")

1. **Header** — лого + nav (Models, Features, About, Contacts) + CTA-кнопка. Sticky.
2. **Hero** — банер на всю ширину: фонове фото, заголовок, підзаголовок, головний CTA.
3. **Models** — адаптивна сітка карток (~6 реальних марок): фото, марка + модель,
   рядок характеристик, ціна, кнопка "Details".
4. **Features** — 3-4 переваги (іконка + заголовок + текст): гарантія, тест-драйв,
   фінансування, сервіс.
5. **About** — короткий блок про компанію + статистика (роки, продано, клієнти).
6. **Contact** — CTA-блок з простою формою (ім'я, email, повідомлення) + контакти.
   Форма нефункціональна.
7. **Footer** — nav-посилання, соцмережі, копірайт.

## Порядок збірки

Кожен крок закінчується комітом (чекпоінт для відкату):

0. `git init` + `.gitignore` + `ROADMAP.md` → коміт `chore: init project`.
1. Каркас: скелет `index.html` + `reset.css` + `style.css` (змінні, коментарі-банери),
   перевірка Live Server → коміт.
2. Header + Hero (візуальний тон: кольори, шрифти, шкала відступів) → коміт.
3. Сітка Models → коміт.
4. Features + About → коміт.
5. Форма Contact + Footer → коміт.
6. Прохід по адаптивності + фінальне прибирання → коміт.

Після кожного кроку — рев'ю перед наступним.

## Відкрита деталь по контенту

Фото марок: спершу плейсхолдери (блоки кольором / placeholder-сервіс), реальні фото
підставимо пізніше (тут у майбутньому може підключитись Claude Design).

## Перевірка

- Відкрити `index.html` через Live Server → усі 7 секцій на місці.
- Resize (mobile → tablet → desktop): розкладки тримаються, без горизонтального скролу.
- Семантика (один `<h1>`, логічний порядок заголовків), кожен клас за BEM.
- Кожен файл закінчується рівно одним фінальним newline.
